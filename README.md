# Dev Env Installation

## Install premake
- https://premake.github.io/download
- Make sure you can run premake5 from the commandline by adding the file location to the environment path.

## Install msBuild

msbuild is automatically installed with visual studio if you have installed; cpp development;

for Rider you can get it here:
- https://visualstudio.microsoft.com/downloads/
- There is a build tools option;
- do keep in mind this will install VSInstaller
- you will also have to install the cpp development tools; or its individual components
- Also install MSVC v143 (or updated version if its asking for it) as individual component
- Make sure to add msBuild to the environment path;
- Example path location: (C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\MSBuild\Current\Bin)
